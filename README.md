CIBUSmod is a food systems model developed at the [Department of Energy and Technology, Swedish University of Agricultural Sciences (SLU)](https://www.slu.se/en/departments/energy-technology/) within the [MISTRA Food Futures Programme](https://mistrafoodfutures.se/).

To get started look at the [Documentation](https://slu-foodsystems.github.io/CIBUSmod/):link: for guidance on how to install and run the model. [This notebook](notebooks/example_scenario.ipynb) provides an example run of the model and shows how outputs can be visualised and analysed.
